คู่มือแอดมินแบบสั้น — สิ่งที่ทำได้ V7.0

ใช้หลัก ๆ แค่ 2 แท็บ:

1. รายการสิ่งที่ทำได้
   = คลัง Feature กลาง

2. สิ่งที่ทำได้ต่อบริการ
   = ติ๊กว่าแต่ละบริการทำอะไรได้

----------------------------------------
งานประจำวัน
----------------------------------------

เปิด Feature ให้บริการ:
1. ไป “สิ่งที่ทำได้ต่อบริการ”
2. หา serviceName
3. ติ๊ก enabled
4. หน้าเว็บจะแสดง Feature นั้น

ปิด Feature:
เอาติ๊ก enabled ออก

จัดลำดับ:
เลือก sortOrder

เพิ่มรายการใหม่:
- เลือก serviceId
- พิมพ์ชื่อใหม่ใน label
- กด Enter
- ระบบเพิ่มเข้า Catalog ให้อัตโนมัติ

แก้ชื่อไทย/อังกฤษ:
ไป “รายการสิ่งที่ทำได้”
แก้ label / labelEn

ปิด Feature ทั้งร้าน:
“รายการสิ่งที่ทำได้” > enabled = FALSE
