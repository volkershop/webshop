============================================================
สิ่งที่ V6.7 ปรับ
============================================================

1) Backend Public Cache

Cache เฉพาะข้อมูล public:
- Games
- Guides
- Site settings ที่เปิดเผยหน้าเว็บ
- Theme
- FX display data
- Review public config
- Payment methods public config

ไม่ Cache:
- Order status
- Customer identity/token
- Request
- Claim eligibility
- Review eligibility
- createOrder/createRequest/createReview/submitClaim
- ข้อมูล private

TTL:
Site = 60 วินาที
Theme = 60 วินาที
Games = 90 วินาที
Pricing = 120 วินาที
PaymentMethods = 120 วินาที
Guides = 300 วินาที

เมื่อแอดมินแก้ข้อมูล public ผ่าน Sheet
ระบบ v6SpreadsheetEdit จะล้าง cache ให้อัตโนมัติ

ถ้าข้อมูล cache ใหญ่เกิน safe limit:
ระบบจะข้าม cache และอ่านสดตามเดิม
ไม่ทำให้เว็บพัง


2) โหลด Customer + Catalog พร้อมกัน

รุ่นก่อน:
Customer API
↓ รอ
Bootstrap API
↓
แสดงเว็บ

V6.7:
Customer API ─┐
              ├─ ทำพร้อมกัน
Bootstrap API ┘

จึงลดเวลารอแบบต่อคิว


3) งานที่ไม่จำเป็นต่อหน้าแรกถูกเลื่อนไปทีหลัง

ไม่โหลด Reviews ตั้งแต่หน้าแรก
ไม่ render:
- Reviews
- Claims
- Guides
- Zygisk Install

จนกว่าลูกค้าจะเปิด Tab นั้นจริง

สิทธิ์ Review ที่จำในเครื่อง:
ตรวจตอน Browser ว่าง (idle)
ไม่บล็อกการแสดงเกม


4) Search Debounce

ช่องค้นหาเกม/รีวิวรอประมาณ 120 ms
ก่อน rebuild UI

ลูกค้ายังรู้สึกตอบสนองทันที
แต่ลดการ render ซ้ำทุกตัวอักษร


5) WebP + PNG Fallback

ไฟล์เดิมยังอยู่:
banner-0xvolker.png
volker-avatar-circle.png

เพิ่ม:
banner-0xvolker.webp
volker-avatar-256.webp
volker-avatar-768.webp

Browser จะใช้ WebP ก่อน
ถ้าโหลดไม่ได้จะ fallback กลับ PNG เดิม

ดังนั้นไม่เสียความเข้ากันได้


6) Preconnect / Preload

หน้าเว็บเตรียม connection ล่วงหน้าสำหรับ:
- Google Fonts
- Apps Script
- script.googleusercontent.com
- Google Play image host

และ preload เฉพาะ asset ด้านบนที่ต้องเห็นก่อน


============================================================
ผลขนาดรูปหลักจากไฟล์จริง
============================================================

ก่อน:
banner PNG + avatar PNG ≈ 3.25 MB

V6.7 primary above-fold:
banner WebP + avatar 256 WebP ≈ 103 KB

ลด transfer ของรูปหลักประมาณ 96.9%

หมายเหตุ:
นี่คือการลด "ขนาดรูปหลักที่โหลดก่อน"
ไม่ใช่การรับประกันว่าเวลาโหลดทั้งเว็บเร็วขึ้น 96.9%
เพราะเวลาโหลดจริงยังขึ้นกับ Network และ Apps Script


============================================================
ทำไมไม่มี Service Worker
============================================================

V6.7 จงใจไม่ใส่ Service Worker

เพราะแม้ Service Worker ทำ cache ได้แรง
แต่มีความเสี่ยง:
- ลูกค้าเห็น index.html รุ่นเก่า
- Deploy ใหม่แล้ว Browser ยังใช้ไฟล์เก่า
- Debug ยากขึ้น

ตามคำสั่ง "ห้ามกระทบระบบที่ดีอยู่แล้ว"
จึงเลือก optimization ที่ rollback ง่ายกว่า
