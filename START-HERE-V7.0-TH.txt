0xVoLKER Shop Service — V7.0 AVAILABLE FEATURES
ระบบ “สิ่งที่ทำได้ / Available Features”

============================================================
เป้าหมาย
============================================================

เปลี่ยนพื้นที่คำอธิบายยาวบนการ์ดเกมให้เป็นข้อมูลที่ลูกค้าดูแล้วเข้าใจทันทีว่า
บริการของเกมนั้นทำอะไรได้บ้าง

หน้า CARD:
- แสดงหัวข้อ “สิ่งที่ทำได้” / “Available Features”
- แสดง 3 รายการแรก
- ถ้ามีมากกว่า 3 รายการ แสดง +N

หน้า DETAIL:
- แสดงรายการทั้งหมดแบบ Chip
- แยกกลุ่มตามบริการ เช่น บริการทรัพยากร / Zygisk Mod Menu
- ในแต่ละแถวบริการจะแสดง Feature ของบริการนั้นด้วย

รองรับการสลับภาษา TH / EN จากระบบเดิมของเว็บ

============================================================
แท็บใหม่ 2 แท็บ
============================================================

1) รายการสิ่งที่ทำได้
Logical name: FeatureCatalog

ใช้เป็นคลังรายการกลางของทั้งร้าน

คอลัมน์:
id          ระบบสร้าง F001, F002...
groupType   resource / zygisk / other
key         คีย์ภายในระบบ
label       ชื่อภาษาไทย
labelEn     ชื่อภาษาอังกฤษ
enabled     เปิด/ปิดรายการนี้ทั้งร้าน
sortOrder   ลำดับการแสดงผล
note        หมายเหตุ

2) สิ่งที่ทำได้ต่อบริการ
Logical name: ServiceFeatures

ใช้เลือกว่าบริการแต่ละรายการทำอะไรได้บ้าง

คอลัมน์:
id           ระบบสร้าง SF001, SF002...
gameId       ระบบเติมจากบริการ
gameName     ระบบเติมจากบริการ
serviceId    เลือก Service ID จาก Dropdown
serviceName  ระบบเติม
serviceType  ระบบเติม resource / zygisk / other
featureId    ระบบเติม
label        เลือก Feature จาก Dropdown หรือพิมพ์เพิ่มเอง
labelEn      ระบบเติม
 enabled     ติ๊กเพื่อแสดงบนเว็บ
sortOrder    ลำดับการแสดง

วิธีอัปเดตแบบปลอดภัย
============================================================

ก่อนเริ่ม:
- อย่าลบ Code.gs เดิมจนกว่าจะดาวน์โหลด/เก็บสำรองไว้
- อย่าใช้ New deployment
- อย่ารัน setupV6System

STEP 1 — Backend

1. Apps Script > Code.gs
2. Ctrl+A
3. วางไฟล์:
   Code-WebShop-Backend-V7.0-Available-Features.gs
4. Save

STEP 2 — สร้างระบบใหม่

Run:
setupAvailableFeatures100

ผลที่ถูกต้องต้องมีทั้ง:
AVAILABLE FEATURES SETUP OK
AVAILABLE FEATURES DIAG PASS

และท้ายผลควรเป็น:
missing=0
duplicates=0
dangling=0
mismatched=0

ถ้ามีคำว่า FAIL:
- ห้าม Deploy
- อย่า Run ซ้ำหลายครั้ง
- เก็บภาพผล Error/Diagnostic ไว้ตรวจ

STEP 3 — ตรวจโครงสร้าง

Run:
testV6Setup

ต้องขึ้น:
V7.0 TEST OK

Run:
diagnoseAvailableFeatures

ต้องขึ้นต้นว่า:
AVAILABLE FEATURES DIAG PASS

STEP 4 — เลือกสิ่งที่ทำได้

ไปแท็บ:
สิ่งที่ทำได้ต่อบริการ

วิธีใช้:
1. หา serviceName / serviceId ที่ต้องการ
2. ติ๊ก enabled เฉพาะ Feature ที่บริการนั้นทำได้จริง
3. ใช้ sortOrder จัดลำดับ

ตัวอย่างบริการ Resource:
- ติ๊ก แพ็ก
- ติ๊ก ทรัพยากร
- ติ๊ก ตัวละคร
- ติ๊ก คอสตูม

ตัวอย่าง Zygisk:
- ติ๊ก FreeShop
- ติ๊ก Status
- ติ๊ก Cheat Mode
- ติ๊ก Disable Anti-Cheat

ระบบจะไม่เปิด Zygisk Feature ทั้งหมดให้เอง เพื่อป้องกันหน้าเว็บประกาศความสามารถที่บริการจริงยังไม่รองรับ

============================================================
วิธีเพิ่ม Feature ใหม่
============================================================

แบบที่ 1 — เพิ่มจาก Catalog

1. เปิด “รายการสิ่งที่ทำได้”
2. ไปแถวว่าง
3. เลือก groupType
4. ใส่ label
5. ใส่ labelEn
6. ติ๊ก enabled
7. ใส่ sortOrder

ระบบสร้าง id/key และสร้าง Draft ให้บริการประเภทเดียวกัน

แบบที่ 2 — เพิ่มจากบริการโดยตรง

1. เปิด “สิ่งที่ทำได้ต่อบริการ”
2. ไปแถวว่าง
3. เลือก serviceId
4. ที่ label พิมพ์รายการใหม่ เช่น No Cooldown
5. กด Enter

ระบบจะ:
- เพิ่มรายการเข้า Catalog
- สร้าง featureId
- เติม game/service/type
- เตรียม Checkbox enabled

ถ้าพิมพ์ภาษาอังกฤษ ระบบใช้ข้อความเดียวกันเป็น labelEn
ถ้าพิมพ์ภาษาไทย ให้กลับไปใส่ labelEn ที่ “รายการสิ่งที่ทำได้” หนึ่งครั้ง
